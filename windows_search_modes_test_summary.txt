TROUBLESHOOTING
=============================================================================

Issue: "vcruntime140.dll not found"
Solution: Install Visual C++ Redistributable (MSVC builds only)
          https://aka.ms/vs/17/release/vc_redist.x64.exe

Issue: Slow performance on laptop
Solution: • Plug in AC power
          • Ensure good ventilation
          • Set power plan to "High Performance"
          • Close background applications

Issue: "Access denied" when writing output file
Solution: • Run as Administrator
          • Close file if open in another program
          • Move to folder with write permissions

Issue: Program freezes or crashes
Solution: • Update Windows and GPU drivers
          • Try with fewer threads (-t 1)
          • Reduce memory usage (lower -n value)
          • Disable antivirus temporarily

Issue: AVX2/AVX-512 not detected
Solution: • Update BIOS to latest version
          • Enable AVX in BIOS settings
          • Run benchmark: keyhunt.exe --benchmark

Issue: File paths with spaces don't work
Solution: Use quotes: keyhunt.exe -f "C:\My Documents\tests\1to32.txt"

Issue: Progress file not saved
Solution: • Check %USERPROFILE%\.keyhunt\progress\ exists
          • Create manually: mkdir %USERPROFILE%\.keyhunt\progress
          • Run as Administrator

Issue: Antivirus flags keyhunt.exe
Solution: • Add to antivirus exclusions
          • Use official builds from GitHub
          • Compile from source yourself
