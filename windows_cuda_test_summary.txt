================================================================================
TROUBLESHOOTING
================================================================================

Problem: nvcc.exe not found
Solution: Install CUDA Toolkit or specify --cuda-home path

Problem: cudart64_XX.dll not found
Solution: Add CUDA bin directory to PATH or copy DLL to keyhunt directory

Problem: CUDA error: out of memory
Solution: Close other GPU applications, reduce bit range, use smaller bloom filter

Problem: Slow GPU performance
Solution: Enable maximum performance mode (nvidia-smi -pm 1)

Problem: CUDA error: no kernel image available
Solution: Rebuild with correct GPU architecture (--arch sm_XX)
