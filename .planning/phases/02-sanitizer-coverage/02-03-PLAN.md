<task type="auto">
  <name>Task 2: Fix all ASan and UBSan findings to achieve zero</name>
  <files>src/**/*.cpp, src/**/*.c, src/**/*.h</files>
  <action>
For each finding cataloged in Task 1, apply the correct fix:

**HEAP_BUFFER_OVERFLOW / STACK_BUFFER_OVERFLOW:**
- If buffer is too small for SHA256/RIPEMD160 padding: increase buffer size to 64/128 bytes per MEMORY.md note ("sha256_33/sha256_65 write padding IN-PLACE: buffers must be 64/128 bytes").
- If SIMD aligned stack buffer: verify alignment is correct. If ASan false positive on `_mm256_load_si256` from correctly aligned stack variable, annotate the specific function:
  ```cpp
  __attribute__((no_sanitize("address")))  // ASan false positive: 32-byte aligned stack buffer
  void function_name(...) { ... }
  ```
  Document the justification in a comment. Only suppress CONFIRMED false positives.

**USE_AFTER_FREE:**
- Fix the lifetime: ensure the pointer is valid when accessed. Common pattern: local buffer used after function return.

**MEMORY_LEAK:**
- Add matching `free()`/`delete` for every allocation.
- For `new std::atomic<int>[N]{}` from 02-02: ensure `delete[] bsgs_found` is called.
- If ASan reports leaks in test cleanup, add cleanup code to test teardown.
- If ASan `detect_leaks=1` is too aggressive for test infrastructure (one-shot allocations never freed because the process exits), consider `detect_leaks=0` only as a LAST RESORT and document why.

**UB_SHIFT:**
- Ensure shift amount is >= 0 and < bit width of type.
- Common in cryptographic code: `x << 32` where x is uint32_t. Fix by casting to uint64_t first.

**UB_SIGNED_OVERFLOW:**
- Cast to unsigned before the operation: `(unsigned)a + (unsigned)b`.
- In carry-chain code (IntMod.cpp), the `volatile unsigned char c` is already unsigned so should not overflow. If UBSan flags the carry chain, examine whether `_addcarry_u64` intermediates have UB.

**UB_ALIGNMENT:**
- Use `memcpy` instead of cast-and-dereference for unaligned access.
- Or add `__attribute__((aligned(N)))` to the buffer.
