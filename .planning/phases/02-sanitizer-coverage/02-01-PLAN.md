**Part A — MEM-03: gpu_config_t volatile-to-atomic**

1. In `src/config/config.h`, add `#include <atomic>` inside the existing `#ifdef __cplusplus` block at the top (check if it already exists — if not, add it). Also add `#include <stdatomic.h>` in the `#else` (C) block if C11 atomics are needed.

2. Replace the three volatile fields in `gpu_config_t` (lines 154-157):

   BEFORE:
   ```c
   /* Runtime stats (volatile for cross-thread visibility) */
   volatile uint64_t keys_checked;
   volatile uint64_t keys_checked_cur;
   volatile int      should_stop;
   ```

   AFTER:
   ```c
   /* Runtime stats (atomic for cross-thread visibility) */
   #ifdef __cplusplus
   std::atomic<uint64_t> keys_checked;
   std::atomic<uint64_t> keys_checked_cur;
   std::atomic<int>      should_stop;
   #else
   _Atomic uint64_t keys_checked;
   _Atomic uint64_t keys_checked_cur;
   _Atomic int      should_stop;
   #endif
   ```

3. In `src/config/config.cpp`, update the comments about volatile (lines 154, 260) to say "atomic" instead of "volatile". Also update the initialization code — `memset` on `gpu_config_t` will NOT work with `std::atomic` fields. If `keyhunt_config_reset()` or `keyhunt_config_init()` does `memset(&config->gpu, 0, sizeof(gpu_config_t))`, it must instead zero-initialize individual fields:
   ```cpp
   config->gpu.keys_checked.store(0, std::memory_order_relaxed);
   config->gpu.keys_checked_cur.store(0, std::memory_order_relaxed);
   config->gpu.should_stop.store(0, std::memory_order_relaxed);
   ```
   If the struct uses aggregate initialization or designated initializers, update those to use `{}` for atomic fields.

4. Search for ALL sites that read/write these three fields and update them:
   - `config->gpu.keys_checked = X` → `config->gpu.keys_checked.store(X, std::memory_order_relaxed)`
   - `X = config->gpu.keys_checked` → `X = config->gpu.keys_checked.load(std::memory_order_relaxed)`
   - For `should_stop`, use `memory_order_release` for writes and `memory_order_acquire` for reads (it's a cross-thread stop signal).
   Use `grep -rn "keys_checked\|keys_checked_cur\|gpu.*should_stop" src/` to find all sites.
