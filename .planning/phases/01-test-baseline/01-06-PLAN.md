Add these tests to test_hash.cpp, registered in run_hash_tests():

```
sha256sse_1B_standalone:
  - Prepare 4 identical pre-padded 64-byte input blocks (uint32_t[16] each)
  - Use the "abc" test vector: message "abc" (3 bytes) padded to SHA256 block format
  - Padding format: bytes 0-2 = "abc", byte 3 = 0x80, bytes 4-61 = 0x00, bytes 62-63 = big-endian bit length (0x18 = 24 bits)
  - Call sha256sse_1B(i0, i1, i2, i3, d0, d1, d2, d3) with aligned output buffers (32 bytes each, 16-byte aligned)
  - Verify each d0-d3 matches the known SHA256("abc") = ba7816bf 8f01cfea 414140de 5dae2223 b00361a3 96177a9c b410ff61 f20015ad
  - This covers the full sha256sse_1B function including the unpack/shuffle output section

sha256sse_2B_standalone:
  - Prepare 4 identical pre-padded 128-byte (2-block) input blocks (uint32_t[32] each)
  - Use a 65-byte message (simulating an uncompressed pubkey): 0x04 followed by 64 bytes of known data
  - First block (64 bytes): the first 64 bytes of the padded message
  - Second block (64 bytes): remaining 1 byte + 0x80 padding + 0x00 fill + big-endian bit length (0x0208 = 520 bits)
  - Call sha256sse_2B(i0, i1, i2, i3, d0, d1, d2, d3)
  - Cross-validate: compute SHA256 of the same 65-byte message using scalar sha256() function
  - Verify all 4 outputs match the scalar result

sha256_ripemd160_sse_1B_fused:
  - Prepare 4 pre-padded 1-block inputs (same as 1B test above, "abc")
  - Call sha256_ripemd160_sse_1B(i0, i1, i2, i3, d0, d1, d2, d3)
  - Cross-validate: compute SHA256("abc") with scalar, then RIPEMD160 of that SHA256 output with scalar ripemd160_32()
  - Verify all 4 outputs (20 bytes each) match the scalar pipeline result

sha256_ripemd160_sse_2B_fused:
  - Prepare 4 pre-padded 2-block inputs (65-byte simulated uncompressed pubkey)
  - Call sha256_ripemd160_sse_2B(i0, i1, i2, i3, d0, d1, d2, d3)
  - Cross-validate against scalar sha256(65-byte) then ripemd160_32()
  - Verify all 4 outputs match
```
