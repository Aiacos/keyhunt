  <files>.clang-tidy, Makefile, compile_commands.json, src/sort/sort.h</files>
  <action>
1. Create .clang-tidy configuration file:
   ```yaml
   Checks: >
     -*,
     bugprone-*,
     clang-analyzer-security.*,
     -bugprone-easily-swappable-parameters,
     -bugprone-exception-escape
   HeaderFilterRegex: 'src/(modes|util|io|search|config|gpu|platform)/.*'
   WarningsAsErrors: ''
   ```
   - Exclude bugprone-easily-swappable-parameters (too noisy for SIMD code per Research Pitfall 2).
   - Exclude bugprone-exception-escape (C++ exception handling not used in this codebase).
   - HeaderFilterRegex excludes vendored secp256k1/ and gmp256k1/.

2. Generate compile_commands.json: Run `bear -- make clean all`.

3. Fix reserved identifiers in sort.h (Research Pitfall 3):
   - Rename `_swap` -> `kh_swap`, `_sort` -> `kh_sort`, `_introsort` -> `kh_introsort`, `_insertionsort` -> `kh_insertionsort`, `_partition` -> `kh_partition`.
   - Update all callers of these functions.

4. Add hardening flags to Makefile (STR-08):
   ```makefile
   HARDEN_FLAGS := -D_FORTIFY_SOURCE=3 -fstack-protector-strong -fcf-protection
   ```
   - Add HARDEN_FLAGS to CXXFLAGS and CFLAGS in the main build target.
   - Do NOT add to sanitizer builds (ASan/UBSan already have their own flags, and FORTIFY_SOURCE requires -O1+).
   - Verify these work with the existing -O2 optimization level.

5. Add Makefile targets for static analysis:
   ```makefile
   .PHONY: clang-tidy cppcheck
   clang-tidy: compile_commands.json
   	find src/ -name '*.cpp' -not -path 'src/secp256k1/*' -not -path 'src/gmp256k1/*' \
   	  | xargs -P4 clang-tidy -p . 2>&1 | tee clang-tidy-report.txt
   	@! grep -c "warning:" clang-tidy-report.txt || echo "Warnings found"

   cppcheck:
   	cppcheck --enable=warning --error-exitcode=1 \
   	  --suppress=dangerousTypeCast:src/secp256k1/Int.h \
   	  --suppress=dangerousTypeCast:src/gmp256k1/Int.h \
   	  -Isrc src/ 2>&1 | tee cppcheck-report.txt
   ```

6. Verify build with hardening flags: `make clean all` must succeed with zero warnings.
