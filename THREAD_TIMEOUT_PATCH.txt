# Thread Timeout Patch
# Apply this patch manually to keyhunt.cpp around line 2116-2139

## Location 1: Thread waiting loop for bPload_2blooms (line ~2116)

BEFORE the loop `for(j = 0 ; j < NTHREADS ; j++)`, ADD:

```cpp
// Add timeout to prevent infinite waiting
static int wait_cycles = 0;
const int MAX_WAIT_CYCLES = 30000; // ~30 seconds with 1ms sleep
```

INSIDE the loop, AFTER `FINISHED_THREADS_COUNTER++`, ADD:

```cpp
wait_cycles = 0; // Reset timeout on progress
```

AFTER the loop `for(j = 0 ; j < NTHREADS ; j++)`, BEFORE `}while(...)`, ADD:

```cpp
// Check for timeout
if(++wait_cycles > MAX_WAIT_CYCLES) {
    fprintf(stderr,"\n[E] Thread timeout: No progress in 30 seconds\n");
    fprintf(stderr,"[E] Completed %lu/%lu threads, try reducing thread count\n",
            FINISHED_THREADS_COUNTER, THREADCYCLES);
    break;
}

usleep(1000); // 1ms sleep to prevent CPU spinning
```
