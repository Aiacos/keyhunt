# Global Variables Removed from keyhunt.cpp (Subtask 4-1)

This file documents all global variable declarations removed from src/keyhunt.cpp
as part of the migration to keyhunt_config_t structure system.

## Migration Path:

All removed variables have been mapped to fields in keyhunt_config_t:
- Search config → config->search.*
- BSGS config → config->bsgs.*
- GPU config → config->gpu.*
- Runtime state → config->runtime.*
- Auto-tune config → config->autotune.*

See MIGRATION_GUIDE.md for complete mapping table.

## Note:

Functions that still reference these variables (cpu_use_y_parity_for_compressed_btc, 
gpu_keys_checked_total_u64, hybrid_get_gpu_range_percent_default) use extern 
declarations temporarily. These will be refactored to accept config parameters 
in future subtasks.
