# Keyhunt Hybrid Performance Optimization Design

**Data:** 2026-01-21
**Obiettivo:** Ottimizzazione completa CPU+GPU+Hybrid con focus su portabilità e scalabilità
**Approccio:** Incrementale (un miglioramento alla volta, testato prima di procedere)

---

## Panoramica

Piano di 8 incrementi per migliorare:
1. **Performance** - GPU kernel, CPU-GPU pipeline, memory
2. **Scalabilità** - Multi-GPU, distributed computing
3. **Usabilità** - Config system, auto-detection

## Incremento 1: Sistema di Configurazione

### Filosofia
"Zero-config by default, tune if needed"

### File: `keyhunt.conf` (formato INI)

```ini
# Auto-generated by keyhunt - edit only if needed
mode = hybrid
threads = auto
gpu = auto

# Optional tuning (uncomment to override auto-detection)
# gpu_devices = 0,1
# batch_size = 1024
```

### Parametri supportati

| Parametro | Default | Descrizione |
|-----------|---------|-------------|
| `mode` | `auto` | cpu / gpu / hybrid / auto |
| `threads` | `auto` | Numero o "auto" |
| `gpu` | `auto` | on / off / auto |
| `gpu_devices` | `all` | Lista GPU (0,1,2) |
| `batch_size` | `auto` | Per tuning avanzato |
| `memory_limit` | `75%` | RAM massima |

### Nuovi flag CLI

- `-c, --config <file>` - Carica configurazione da file
- `--save-config` - Salva configurazione corrente dopo auto-detect
- Se `./keyhunt.conf` esiste, viene caricato automaticamente

### File coinvolti

- **Nuovo:** `config.c/h` - Parser INI (~100 righe, no dipendenze esterne)
- **Modifica:** `keyhunt.cpp` - Integrazione nel parsing argomenti

### Performance Score

```c
cpu_score = cores * (1 + 0.5*avx2 + 1.0*avx512)
gpu_score = sm_count * clock_mhz * memory_bandwidth_factor
hybrid_ratio = gpu_score / (cpu_score + gpu_score)
```

## Incremento 6: Work Stealing Adattivo

### Scheduler adattivo

```c
typedef struct {
    double cpu_mkeys_sec;
    double gpu_mkeys_sec;
    double cpu_ratio;
    double gpu_ratio;
    uint64_t cpu_chunk_size;
    uint64_t gpu_chunk_size;
} adaptive_scheduler_t;
```

### Algoritmo

```c
void update_ratios(adaptive_scheduler_t *s) {
    double total = s->cpu_mkeys_sec + s->gpu_mkeys_sec;
    if (total > 0) {
        s->gpu_ratio = s->gpu_mkeys_sec / total;
        s->cpu_ratio = s->cpu_mkeys_sec / total;
    }
    // Chunk size proporzionale al throughput
    s->gpu_chunk_size = BASE_CHUNK * (1.0 + s->gpu_ratio * 4);
    s->cpu_chunk_size = BASE_CHUNK * (1.0 + s->cpu_ratio * 4);
}
```

```
  Efficiency:       98.2%
```

```c
#define CACHE_LINE 64
```

```c
for (int i = 0; i < batch_size; i += 8) {
    __builtin_prefetch(&bloom->data[hash[i+8] >> 3], 0, 3);
```

### Memory pool

```c
typedef struct {

void* pool_alloc(mem_pool_t *p, size_t size);
```

```
│Worker1│ │Worker2│ │Worker3│
```

**Worker → Coordinator:**
```json
{"type": "register", "id": "worker1", "perf_score": 612.5}
{"type": "request_work"}
```
